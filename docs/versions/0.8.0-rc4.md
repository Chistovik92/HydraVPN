# 0.8.0-rc4 — «Мои серверы» сервер-сначала, AmneziaWG и ByeDPI снова работают

Пре-релиз от 14.10.2026, ветка `master`. Предыдущая: [0.8.0-rc3](0.8.0-rc3.md); следующая по ветке панелей — [0.8.1-b](0.8.1.md).
Запрос владельца (14.10.2026): в rc3 нет полноценного управления сервером AmneziaWG, не работают обход DPI (ByeDPI) и AWG
(«недоступен»), нельзя ввести данные других протоколов; запоминать вход, сначала доступ к серверу — потом выбор служб, полная очистка.

## «Мои серверы» — как устроено теперь

1. **Добавить сервер**: адрес и пароль root (или SSH-ключ, с паролем к ключу) → отпечаток SSH-ключа сервера (закрепляется) → вход и
   проверка → сервер в списке. Флажок «Запомнить вход» (по умолчанию включён): пароль/ключ хранятся **зашифрованными** —
   Android Keystore (`my_servers_login.dat`), Windows — DPAPI, Linux/macOS — AES-GCM ключом из файла профиля 0600
   (`servers-login.dat` рядом с `hydra.json`). Без флажка — только в памяти до закрытия приложения. Тот же адрес повторно — запись
   обновляется, не дублируется.
2. **На карточке сервера**: состояние (на связи / недоступен, система, аптайм, нагрузка, память, диск), «Проверить», «Данные входа»
   (сменить или забыть), «Перезагрузить», «Переименовать»; разделы служб:
   - **AmneziaWG** — «Установить» (поколение 1.0 / 1.5 / 2.0 / 3.x, порт, открыть порт в файрволе) → проверка сервера и план
     → установка с журналом; устройства (последнее рукопожатие и трафик каждого, конфиг + QR, удалить), «Добавить устройство»,
     «Перезапустить», «Удалить AmneziaWG» (с закрытием порта, если его открывала Hydra);
   - **Узел OpenFlux** — установка, ссылка `openflux://`, перезапуск, удаление;
   - «Ещё»: отпечаток, **«Очистить сервер полностью»**, «Убрать из списка».
3. **Полная очистка** удаляет всё, что ставила Hydra, независимо от записи в приложении: службу `hydra-awg`, конфиги AmneziaWG
   с меткой Hydra, программы `amneziawg-go/awg/awg-quick`, настройку пересылки, узел OpenFlux целиком (штатный `uninstall` его
   скрипта), порты файрвола из `/etc/hydra/fw.list`, каталог `/etc/hydra`, временные файлы. Чужие программы не трогаются; запись
   сервера и вход остаются — можно поставить заново.
4. **Копия состояния на сервере** `/etc/hydra/awg.json` (0600, только root): ключи и устройства AmneziaWG. Второе устройство
   (телефон + ПК), добавив тот же сервер, сразу видит службу и устройства и может ими управлять. Серверы, поставленные rc1–rc3
   без копии, восстанавливаются по конфигу сервера (устройства без закрытых ключей — «создано на другом устройстве»), копия
   дописывается.
5. Если сохранённый пароль перестал подходить — он забывается, и Hydra спрашивает новый.

Код: `shared/src/commonMain/kotlin/ru/gidravpn/hydra/servers/` — `MyServersManager` (сценарии), `MyServerService` (шаги и сверка
с сервером), `ServerOps` (проверка, копия состояния, очистка), `CredentialVault` (хранилище входа); платформенное шифрование —
`app/.../data/servers/KeystoreCipher.kt`, `desktop/.../core/DesktopVault.kt`. Экраны — `MyServersScreen.kt` (Android, ПК).
Инструкция для пользователя — [`../SERVERS.md`](../SERVERS.md).

## Как проверено

- Юнит-тесты: Android 195, ПК 111, HydraKit `ManualLinkTests` (Swift 6.1 в WSL) — без провалов. Новые: порядок UAPI, AWG-конфиг
  не принимается за WireGuard, ручной ввод всех протоколов (Android через Robolectric, ПК, iOS), разбор состояния сервера и сверка,
  хранилище входа (шифрование, перезагрузка, чужой ключ), проверка адреса без сети, состав очистки.
- Живой Linux (WSL Ubuntu 26.04, systemd): `ServerFirstTest.serverFirstEndToEndLive` — добавить сервер → поставить AmneziaWG →
  устройства → проверка (служба работает, 2 пира) → «второе устройство» подхватывает сервер с устройствами → удалить службу →
  поставить снова → полная очистка (на сервере ничего не осталось); `AwgServerLiveTest` — рукопожатие всех четырёх поколений.
- Эмулятор Android 15 (полный APK): ByeDPI подключается, страница открывается через VPN; «Мои серверы» — добавление WSL-сервера
  с сохранением входа, установка AmneziaWG 2.0, профиль сохранён как AWG, пинг 3 мс, подключение — страница открылась,
  сервер видит десятки КБ в обе стороны; очистка сервера с телефона.
- **Не проверено:** настоящий VPS (x64/arm64), телефон владельца, ПК вживую с VPS, iOS-экран ручного ввода (собирается только в
  macOS-CI), узел OpenFlux на живом сервере в этом выпуске.

## Известные ограничения

- Подключение к AmneziaWG на ПК не поддерживается (сервер с ПК ставится и обслуживается; подключаться — с телефона) — в очереди.
- Запись «подключённой панели» из альфы 0.8.1-a в rc4 видна как пустой сервер — её стоит убрать из списка (в 0.8.1-b показывается правильно).
