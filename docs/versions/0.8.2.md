1. **A0** (ПК, «Мои серверы» — и во второй оболочке Hydra Classic) и **A7** (установщик Windows 10) — находки владельца, первыми.

5. **A8–A11** (PasarGuard, Remnawave, Nexora, self-steal) — Docker на стенде; Remnawave и self-steal — с доменом владельца.
Каждый пункт — отдельным коммитом в `claude/0-8-2-alpha`, тесты и живой прогон до перехода к следующему.

### Долг, найденный в 0.8.1 (делается в альфе попутно)

- **Дубли `app/` и `shared/`:** в rc2 Android-копия `XrayConfigBuilder` не знала XHTTP, а `EngineToggles`, `SingBoxConfigBuilder`, `LinkParser`
  живут в двух копиях. Свести в `:shared` (как уже сделано для `servers/`, `update/`, `router/` — копированием исходников в сборку app).
- **Проверка release-сборки в CI:** фикс http-подписок в rc1 не действовал в release (манифест не ссылался на `network_security_config`,
  а debug разрешает http сам). Нужна проверка собранного release-манифеста (aapt2 dump) — `networkSecurityConfig` на месте.
- Живые тесты панелей одной командой (`scripts/live-panels.sh`: WSL-пароль, sshd, `HYDRA_*`, ядра из сборки ПК) — сейчас это ручной рецепт.

### Nexora — ноды (разведка 16.10.2026)

Устроено так: в панели заводится нода (имя, адрес, порт **62050**), панель выдаёт **одноразовый токен установки**; на сервере ноды —
`curl -fsSL https://ПАНЕЛЬ/install-node.sh | bash -s -- --panel ПАНЕЛЬ --token ТОКЕН` (бинарь — с самой панели, токен меняется на mTLS-
сертификат панели, нода выпускает свой; панель закрепляет его при первом подключении). Нода без своей базы, всё получает от панели;
обслуживает подключения только после назначения ей **шаблона**. Панель умеет ставить ноду и сама по SSH. Число нод ограничивает лицензия
панели (бесплатно — 1 нода, 25 пользователей); исходники закрыты, API на сайте документации (docs.nexora-panel.org) упоминается, но не
описан. **В бете:** если появится описание API или выпуск ≥ 0.1 — установка панели и нод из Hydra по этой схеме (токен → `install-node.sh`
→ порт 62050 только для панели → шаблон); иначе — только «Добавить ноду» через сайт панели в окне Hydra.
