# План 0.7.17 - безопасность по итогам ревизии кода

Запрос владельца 10.10.2026: провести ревизию всего проекта на баги и составить план исправления (выпущено в тот же день). Затрагивает Android, ПК и iOS (один файл).

## Задачи и результат

| № | Задача | Результат |
|---|---|---|
| 1 | SSTP не проверял имя хоста сертификата | включена проверка `HTTPS` (`endpointIdentificationAlgorithm`), имя берётся из SNI/адреса профиля; SNI отправляется и при `allow_insecure` |
| 2 | Блокировка приложения переживала смерть процесса | `unlocked` больше не восстанавливается из `savedInstanceState`; ярлык, deep-link и «Поделиться» ждут разблокировки |
| 3 | Импорт по ссылке без подтверждения | диалог «Импортировать по ссылке?» (5 языков) для `vless://`, `olcbox://` и остальных схем |
| 4 | Обновления без контрольной суммы | файл без SHA-256 в метаданных релиза не устанавливается |
| 5 | `isLocalHost` пропускал `http://10.0.0.1.evil.com` | исправлено на Android, в `:shared` и на iOS; негативные тесты |
| 6 | Windows: сценарий стража прокси лежал файлом в `%APPDATA%` | сценарий передаётся `-EncodedCommand`; переменные `HYDRA_*` игнорируются при запуске от администратора |
| 7 | Подписки на Android шли за редиректом https -> http | `followSslRedirects(false)` |
| 8 | Опечатка в журнале переподключения | `${ReconnectPolicy.MAX_ATTEMPTS}` |

## Не вошло

- Конфиги ядер (`config.json`, `xray.json`) при запуске от администратора лежат в каталоге пользователя - нужен каталог с ACL только для администраторов (в очереди).

## Критерии готовности и что проверено

- Юнит-тесты `:app` (stub) и `:desktop`; сборка native-варианта в `scripts/release.sh`.
- Не проверено на устройстве: SSTP с проверкой имени, диалог импорта, повторная блокировка после смерти процесса.
