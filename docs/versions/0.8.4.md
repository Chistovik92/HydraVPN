# 0.8.4 — libbox 1.14.4 и NX Panel: план alpha → beta → rc → release

Ветка разработки: `claude/0-8-4-alpha` (от `master` = 0.8.3, коммит `8693155`).
Порядок: **0.8.4-a** → исправления `-a2…` → **0.8.4-b** → исправления `-b2…` → **0.8.4-rcN** → **0.8.4**.

## Что уже записано в документации проекта

Основной объём 0.8.4 собран из `docs/ROADMAP.md`, архивной дорожной карты, `docs/ECOSYSTEM.md`,
`RELEASE-0.8.3-PLAN.md`, `RELEASE-0.8.3-ANALYSIS.md`, `docs/versions/0.8.2.md`, `docs/versions/0.8.3.md`,
`docs/HANDOFF.md` и `API-INTEGRATION-MAP.md`:

1. **sing-box/libbox 1.14.4 на Android и iOS.** В 1.13+ удалён отдельный `BoxService`: сервисом управляет
   `CommandServer` через `startOrReloadService(config, OverrideOptions)` / `closeService()`. `PlatformInterface`
   расширен (`ConnectionOwner`, уведомления, neighbor monitor и другие методы), `CommandClient` теперь работает с
   новым gRPC API. Сохранить патч REALITY/X25519MLKEM768, статистику, маршрутизацию, Xray-мост, ByeDPI, olcRTC/OpenFlux,
   смену сети и корректную остановку.
2. **Nexora 0.0.6 → NX Panel 0.1.x.** Это отдельная миграция, а не смена строки версии: новые `/opt/nx-panel`,
   `/var/opt/nx-panel`, служба `nx-panel`, перенос данных и проверка API. Обязательны резервная копия, идемпотентность,
   откат и живой стенд.
3. **Новые возможности sing-box:** Naive, OpenVPN, OpenConnect, Snell. Их наличие в ядре не означает готовую поддержку
   в Hydra: парсер, модель, UI, генератор конфигов и тесты добавляются только после стабилизации обновлённого ядра.
4. **MASQUE — условный эксперимент.** Не является обязательным содержимым 0.8.4. Нужны подтверждённая поддержка в
   выбранном sing-box, отдельный технический разбор и реальный сервер. Не блокирует бета, rc или выпуск.
5. **UX/диагностика:** понятные ошибки и диагностика соединения — после сборки отзывов на альфу; не смешивать с миграцией
   ядра без воспроизводимого случая.
6. **Хвост 7a:** использовать callback внешней RPC-команды остановки; не считать обрыв канала статистики смертью ядра.
   Отдельный asynchronous core-death API в gomobile-биндинге 1.14.4 отсутствует, как и в прежнем API 1.12.25.

Правила без изменений: не ломать работающее; каждый этап выпускается только как pre-release до личной проверки владельца;
все платформы собираются общим `scripts/release.sh`; в журнале явно разделять автоматические и живые проверки.

  чтобы проверять release-ветку без pull request в `master`.
- **Выполнено (21.11.2026):** полный прогон `:app:testNativeDebugUnitTest` — **210 тестов, 0 ошибок**;
  `:desktop:test` — **199 тестов, 0 ошибок, 23 пропущено**. Все **31** сгенерированных Android-конфига и ранее
  все **102** desktop-конфига проходят `sing-box check` 1.14.4.
- **Исправлен регрессионный блокер Android:** генератор безусловно включал TLS у VLESS, в том числе для
  `security=none`; локальный сервер поэтому получал TLS ClientHello (`unknown version: 22`). Теперь TLS добавляется
  только при включённой защите. Добавлен тест `vlessWithoutTlsDoesNotEnableTls`: до исправления он падал, после — проходит.
- **Выполнено:** полный APK установлен на очищенный эмулятор Android 15 x86_64; sing-box 1.14.4 запускается,
  `tun0` поднимается, статистика подключается. Через локальный VLESS `security=none` Chrome открыл HTTPS
  `https://example.com`; сервер подтвердил реальные исходящие TCP/UDP-подключения. Disconnect убирает `tun0`,
  повторный Connect восстанавливает туннель и HTTPS; Wi-Fi off/on не разрывает VPN, HTTPS после смены сети работает.
- **Review перед выгрузкой:** `:desktop:classicDist` собрал все четыре Classic-пакета; официальные архивы
  sing-box 1.14.4 для x86/x64/armv7 скачиваются из SagerNet и проходят SHA-256. Живые тесты используют
  версионированный `/tmp/sb-1.14.4`, поэтому старый кэш 1.12.x больше не маскируется под новое ядро.
- **Проверен callback остановки:** `serviceStop()` в 1.14.4, как `postServiceClose()` в 1.12.25, относится к
  внешней команде остановки, а не к asynchronous core-death. Регрессии относительно 0.8.3 здесь нет; обрыв
  канала статистики намеренно только логируется и не гасит рабочий VPN. Комментарии в коде уточнены.
- **Ограничение проверки ПК:** TUN E2E останавливается на `configure tun interface: Access is denied.` из-за
  отсутствия административных прав; PROXY E2E (HTTP, SOCKS5 и Clash delay) проходит.
- **Не выполнялось:** сборка `Libbox.xcframework`/Xcode на macOS, подключения к внешним живым серверам, iPhone,
  продолжительная работа и стенд Nexora. Поэтому альфа пока не готова к выпуску.

## Критерий готовности всей версии

Минимальный обязательный выпуск 0.8.4 — прежняя функциональность Hydra на sing-box/libbox 1.14.4 плюс безопасная
миграция NX Panel. Новые протоколы и MASQUE не должны удерживать выпуск, если для них нет тестового сервера или они
дестабилизируют основной объём; решение фиксируется в этой заметке перед бетой.
