## Правила (решения владельца)

- **Не ломать сделанное.** Если новое ломает существующее — это чинится в том же выпуске, всегда. Цель — стабильно работающий
  продукт (14.10.2026).
- **Пре-релизы, пока владелец не проверил сам.** До его проверки всё выходит как `-a` / `-b` / `-rcN`.
- Каждая версия — релиз всех платформ одним конвейером (`scripts/release.sh`); в CHANGELOG честно пишется, что проверено и где.
- Общий код Android и ПК — `shared/`; iOS — порт на Swift (`ios/Packages/HydraKit`).

## Схема версий (решение владельца 12.10.2026)

`X.Y.Z`: **X** — основная полноценная версия; **Y** — фичи, идеи, промежуточные исправления; **Z** — мелкие исправления или
большая идея по шагам.

| Версия | Что это | Как публикуется |
|---|---|---|
| `X.Y.Z` | обычный релиз | релиз GitHub «последний», приложения предлагают обновление |
| `X.Y.Z-a` (`-a2`…) | **альфа** — непроверенный код, для тестирования | pre-release; ветка не вливается в `master`, пока не проверена |
| `X.Y.Z-b` (`-b2`…) | **бета** | pre-release |
| `X.Y.Z-rcN` | **кандидат в релиз** — почти готово, нужна неглубокая проверка | pre-release; после проверки выходит как `X.Y.Z` |

Порядок: `-a` < `-b` < `-rcN` < выпуск. Пре-релиз не становится «последним» на GitHub. Что предлагает приложение, решает
**«Участвовать в бета-тестировании»** (с 0.8.0): выключено — только выпуски; уровень «Релиз-кандидаты» — ещё и `-rcN`; уровень
«Разработчик» — ещё и `-a`, `-b`. Пакеты ПК получают номер без суффикса (`0.8.0-rc4` → MSI/DEB `0.8.0`).
`versionCode` Android растёт сквозь ветки: 0.8.1-a = 66, 0.8.0-rc4 = 67, 0.8.1-b = 68, 0.8.0 = 69 (следующая бета — 70+).

### Очередь без номера

- **AmneziaWG-подключение на ПК** (сейчас на ПК сервер AmneziaWG ставится и обслуживается, но подключаться к нему — с телефона):
  движок-подпроцесс AmneziaWG → SOCKS5 (как OpenFlux/olcRTC) или wintun на Windows.
- **«Трафик Hydra через VPN» для AmneziaWG**: нужен `protect()` сокетов amneziawg-go до первого пакета и после смены сети (колбэк из Go).
- Отложено до тестового сервера: MS-SSTP по спецификации, SSTP/L2TP на живом сервере, IP/домен split для AWG и SSTP/L2TP.
- Проверки на живых сервисах: TG WS на телефоне и iOS, SmartCaptcha OpenFlux (нужен IPC-клиент ядра), перебор стратегий DPI у провайдеров РФ.
- Из ревизий 0.7.17–0.7.19: ACL каталога конфигов при запуске от администратора, kill switch в TUN на ПК, сведение дублей `app/` и `shared/`
  (в rc4 найдено, что `LinkParser`/`WireGuardParser`/`WireGuardConfigBuilder` в двух копиях расходятся — правки приходится делать дважды).
- Скриншоты README под 0.7.14–0.8.x.

## Принципы безопасности для своих серверов и панелей

Только серверы пользователя и только по его явной команде; команды показываются до запуска; скрипты апстрима — закреплённых
версий с проверкой SHA-256; ничего не открывается наружу без согласия; пароли, ключи и токены не пишутся в журнал и хранятся только
зашифрованными; при ошибке — остановка с понятной причиной.
