# Hydra — инструкция пользователя

Как пользоваться приложением Hydra: подключение, серверы, панели, маршрутизация, обновления.
Это руководство для **пользователя**; устройство проекта — [ARCHITECTURE.md](ARCHITECTURE.md),
сборка — [BUILD.md](BUILD.md), протоколы и форматы ссылок — [PROTOCOLS.md](PROTOCOLS.md).

---

## 1. Установка

| Платформа | Как ставить |
|---|---|
| **Android 8+** (телефон, планшет, Android TV) | Скачайте `Hydra-full-<версия>-<архитектура>.apk` из [релиза](https://github.com/Chistovik92/HydraVPN/releases) (обычно `arm64-v8a`) и откройте его. Разрешите установку из источника, при первом запуске разрешите **создание VPN-подключения** — без него туннель не работает. |
| **Windows 10/11** | `…-windows-x64.msi` или `.exe`. Установщик работает **без прав администратора**. Если Hydra уже запущена (значок в трее) — закройте её («Выход»), особенно если она работает в режиме TUN от администратора. |
| **Windows 7 / 32-бит (Hydra Classic)** | `…-classic.zip`: распаковать в отдельную папку, запустить `Hydra.vbs`. Нужна Java 11+. |
| **Linux x64 / arm64** | `.deb` / `.rpm` — пакетом; `.AppImage` — дать право на выполнение и запустить; `.tar.gz` — распаковать и запустить `bin/Hydra`. |
| **macOS 12+** | `.dmg` под вашу архитектуру (Apple Silicon — `arm64`, Intel — `x64`), перетащить Hydra в «Программы». При первом запуске — ПКМ → «Открыть» (приложение вне App Store). |
| **iOS 17+** | `.ipa` без подписи: ставится через AltStore / Sideloadly (переподпись). |

- **Обновления** приложение скачивает само: кнопка «Обновить» в настройках обновлений грузит файл под вашу систему,
  проверяет SHA-256 и запускает установку; portable-версии заменяют свои файлы сами. iOS отдаёт `.ipa` в «Поделиться».
- **Антивирус на Windows** может предупредить (см. [README](../README.md#скачать)): код открыт, SHA-256 в релизе;
  на время установки можно добавить `%LOCALAPPDATA%\Hydra` в исключения.

## 2. Первый запуск

1. **Главный экран** — большая кнопка подключения, срок и трафик подписок (если вошли в аккаунт).
2. Чтобы подключаться, нужен хотя бы один сервер (раздел 3) или аккаунт бота (раздел 4).
3. Язык, тема, значок — в «Настройках» (Android: русский, английский, украинский, персидский, китайский; ПК — русский).

## 3. Серверы и подписки

Вкладка «Серверы» — все источники подключений:

- **Подписка** — ссылка-подписка из панели (3x-ui, x-ui, s-ui, PasarGuard, Remnawave, Marzban) или любая base64-подписка:
  «Добавить подписку» → вставить ссылку → серверы появляются списком и обновляются сами.
- **Одиночные ссылки**: `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `tuic://`, `wireguard://`, `awg://`, `sstp://`, `l2tp://` — вставить из буфера, отсканировать **QR** (камера или фото), импорт `.conf` WireGuard/AmneziaWG.
- **Мои серверы** — свой VPS по SSH (адрес + пароль или ключ; отпечаток закрепляется, вход можно запомнить зашифрованно):
  - Hydra ставит на сервер **AmneziaWG** (устройства, конфиги, QR, перезапуск, удаление) и **узел OpenFlux**;
  - «Установить 3x-ui» (рекомендуемая панель), s-ui или x-ui — Hydra придумывает логин/пароль, для 3x-ui сразу создаёт подключение VLESS + REALITY и подписку;
  - «У меня уже есть панель» — подключить готовую 3x-ui по адресу и токену;
  - PasarGuard и Remnawave — установка из Hydra (Docker), сайт панели открывается через защищённый туннель;
  - **Ноды**: на карточке 3x-ui / PasarGuard / Remnawave — «Ноды» → «Добавить ноду»: второй сервер становится нодой, порты открыты только для главного сервера; при создании подключения выбирается, где его создать — на главном сервере или на ноде;
  - «Очистить сервер полностью» убирает всё, что ставила Hydra (копия базы панели сохраняется перед удалением).
- **Hydra Classic** — вкладки те же, без окна сайта панели.

## 4. Аккаунт бота «Радар»

Профиль → вход по **одноразовому коду** (в боте: «VPN» → «Подключить приложение»). После входа:

- подписки, выданные в боте, заводятся сами и обновляются раз в 6 часов;
- на главном экране — срок действия и трафик;
- доступен **приватный DNS** Hydra VPN (настройка «Частный DNS» / DNS-раздел настроек).

Токен хранится защищённо (Android Keystore / iOS Keychain / файл только для владельца на ПК).

## 5. Подключение

- Главная кнопка подключает/отключает VPN. Подключение берётся из выбранного **профиля/сервера** («Серверы» → выбрать).
- Если подписок и серверов нет — работает **«Обход DPI» без сервера** (ByeDPI): профиль «Обход DPI» пускает трафик «напрямую» через обход. Стратегию подбирает **мастер подбора**: он проверяет 60 готовых стратегий по спискам сайтов и показывает понятный итог («открылось 11 из 12»); найденную стратегию можно сохранить.
- **Telegram не открывается?** Включите **TG WS (Telegram по WebSocket)** — без своего сервера; кнопка «Подключить Telegram к прокси» в настройках и на главном экране.
- Видно, каким ядром идёт подключение («Xray (REALITY)» / «sing-box» и т. п.).
- Android: плитка в быстрых настройках и виджет; ПК: трей, автозапуск, раздача VPN в локальную сеть.

## 6. Маршрутизация («Маршрутизация» — вкладки)

- **Приложения/Программы** — кто идёт через VPN; для отдельного приложения можно назначить свой выход.
- **Сайты и IP** — правила «домен / IP / страна / порт / протокол → выход» с «И»/«НЕ», группы выходов («авто»/«ручной»), цепочки «сервер через обход DPI или другой сервер».
- **Обход DPI** — стратегии ByeDPI, списки доменов, geo-базы (пресет «Заблокированное в РФ → обход DPI»).
- **Выходы** — серверы и обходы, доступные правилам.
- **Профили маршрутизации** («Дом», «Поездка») — переключают наборы правил целиком.
- **Раздельное туннелирование**: пресет «Российские приложения напрямую», исключения по приложениям/IP/странам.

## 7. Безопасность

- **Kill Switch** — блокирует трафик, если туннель упал (включается в настройках).
- **Блокировка приложения** отпечатком / PIN / Face ID; скрытие ключей на экранах.
- Ключи и токены не показываются целиком; отпечатки серверов закрепляются при первом входе.

## 8. Обновления и каналы

Настройки → «Обновления»: уровень канала — **«Релиз»** (только выпуски), **«Релиз-кандидат»** (`-rc`) или
**«Разработчик»** (`-a`, `-b`, `-rc`). Без изменения канала приходят только стабильные выпуски.
Обновление ставится поверх старой версии, данные сохраняются.

## 9. Если что-то не работает

| Симптом | Что делать |
|---|---|
| Не подключается конкретный сервер | Проверьте ссылку/подписку; посмотрите, каким ядром идёт подключение. REALITY-подключения идут через Xray — не отключайте его в «Ядрах» |
| Сайты открываются, но медленно | Обход DPI → мастер подбора стратегии; для WireGuard на Android убедитесь, что включён тумблер AmneziaWG (быстрое ядро) |
| Интернет пропал после смены сети (Wi-Fi ↔ LTE) | Подождите до 10 с — туннель восстанавливается сам; не помогло — переподключите VPN |
| Telegram не открывается | TG WS (раздел 5) или MTProto-прокси |
| Windows: установщик не ставится | Закройте Hydra в трее (особенно режим TUN от администратора), запустите установщик ещё раз |
| Windows: антивирус ругается | См. README «Скачать» — ложное срабатывание, SHA-256 в релизе |
| Панель не открывается извне | Так и задумано («Закрыть панель извне»): сайт панели — через туннель Hydra |
| Всё остальное | Настройки → журнал/диагностика; вопросы — [Telegram-поддержка](https://t.me/+WWJFBZVhxBs4ZmNi) |
