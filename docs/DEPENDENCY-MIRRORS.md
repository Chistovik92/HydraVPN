# Зеркала сторонних исходников

`scripts/mirror-upstreams.sh` сохраняет полные Git-копии (ветки, теги, история) ядер, панелей и нод. Локально сохраняются также служебные `refs/pull/*`, но GitHub их не принимает; при публикации отправляются все ветки и теги со всей историей. Локальные bare-репозитории лежат в `.upstream-mirror/` и не входят в проект. Имя зеркала обычно имеет вид `hydra-mirror-<репозиторий>` (например, `hydra-mirror-Xray-core`); при совпадении имён репозиториев у разных владельцев добавляется владелец: `hydra-mirror-PasarGuard-panel` и `hydra-mirror-Nexora-VPN-panel`. Список источников сохраняется в `.upstream-mirror/UPSTREAMS.txt`.

```sh
scripts/mirror-upstreams.sh                 # создать/обновить локальные копии
scripts/mirror-upstreams.sh --publish       # создать приватные репозитории Chistovik92/hydra-mirror-* и отправить всё
scripts/mirror-upstreams.sh --publish --public
```

Для повторяемой сборки используется и бинарное зеркало `deps` (`scripts/mirror-deps.sh`), а версии и SHA-256 остаются закреплены в сборочных файлах. Git-зеркало сохраняет исходники, но не заменяет проверку артефактов. В `deps` также сохранены два sing-box для legacy Windows 7: исполняемые файлы и лицензия извлечены из опубликованных архивов Hydra Classic, а SHA-256 новых ZIP закреплён в `desktop/build.gradle.kts`.

Обновление компонентов выполняется отдельно: `scripts/check-updates.sh` показывает новые версии; после выбора версии обновляются пины и хеши, зеркала и тесты. Обновление без тестирования трафика не выпускается.
