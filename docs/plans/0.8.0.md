# План 0.8.0 — «Мои серверы»: SSH-слой, свой AmneziaWG, узел OpenFlux

Источник: [`ROADMAP.md`](../ROADMAP.md), раздел 0.8.0. Общий код — пакет `ru.gidravpn.hydra.servers` в `shared/commonMain`
(на Android копируется в сборку тем же `Sync`, что router/update/tgws/pptp; на ПК — зависимость `:shared`).

## Блоки

| № | Блок | Состояние |
|---|---|---|
| A | Ключи X25519 без зависимостей от JDK (`X25519`), случайные параметры AWG 1.0/1.5/2.0/3.x с проверкой правил (`AwgServerParams`), конфиги сервера и клиента (`AwgServerSpec`) | сделано, юнит-тесты (векторы RFC 7748) |
| B | Движок установщика: `Step`, `Installer` (стоп на ошибке, отмена, откат, проверка SHA-256 после загрузки, вырезание секретов), предполётная проверка (`PreflightCheck`) | сделано, тесты на поддельной SSH-сессии |
| C | План развёртывания AmneziaWG (`AwgInstallPlan`): userspace `amneziawg-go` + `awg` + `awg-quick`, служба `hydra-awg`, NAT iptables, ip_forward, файрвол только по согласию, удаление, добавление/удаление клиентов без разрыва (`awg syncconf`) | сделано (на поддельной сессии) |
| D | SSH на JSch (`com.github.mwiede:jsch`): пароль/ключ, закрепление отпечатка хоста, SFTP, потоковый вывод; на Android — BouncyCastle для ed25519 | в работе |
| E | CI: сборка `amneziawg-go` + `amneziawg-tools` (статически, linux amd64/arm64/armv7), `SHA256SUMS`, публикация в релиз; загрузка пакета приложением с проверкой суммы | план |
| F | Интерфейс «Мои серверы» (Android, ПК): добавить сервер (адрес, порт SSH, вход), показать отпечаток, предполётная проверка, «что будет выполнено», журнал, кнопки «Остановить»/«Откатить», список клиентов, QR/`.conf`, автодобавление профиля в «Серверы» | план |
| G | Узел OpenFlux: `NodeConnect/NodePlan/NodeApply/NodeVerify/NodeShareLink` апстрима через тот же SSH-слой, профиль `openflux://` и «поделиться» | план |
| H | Хранение секретов: в памяти сеанса; «запомнить» — Android Keystore / на ПК файл, шифруемый ключом из системного хранилища | план |

## Условия выпуска

- Юнит-тесты A–D, сборка Android (native) и ПК.
- **Живой VPS** (Debian/Ubuntu x64 и arm64): все четыре поколения подключаются клиентами Hydra, `awg show` видит handshake. До проверки в CHANGELOG остаётся «не проверено на сервере».
- iOS — 0.8.3.

## Принципы

Команды показываются до запуска; ничего не открывается наружу без согласия; секреты не пишутся в журнал; закреплённые версии и SHA-256 для всего, что заливается на сервер.
