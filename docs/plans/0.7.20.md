# План 0.7.20 - Telegram по WebSocket для Android без сбоев, iOS-паритет

Запрос владельца 10.10.2026: выполнить то, что было запланировано как «0.7.17» (iOS-паритет); исправить «Недоступен» в Telegram для Android (скриншоты); убрать упоминания авторов идей; использовать форк с MTProto-прокси как образец.

## Задачи и результат

| № | Задача | Результат |
|---|---|---|
| 1 | Telegram для Android: прокси 127.0.0.1:10881 «Недоступен» | TG WS принимает открытый транспорт Telegram (0xEF / intermediate / padded: свой obfuscated2 до ретранслятора) и IPv6-адреса ЦОД; живые тесты на ПК |
| 2 | Режим MTProto-прокси (образец - форк с MTProto-прокси и секретом) | `tg://proxy?...&secret=dd...`, порт 10870, на Android, ПК и iOS; кнопка Telegram открывает его для TG WS |
| 3 | iOS: TG WS | `TgWsServer` (Network.framework) в расширении VPN, выход `tgws`, пресет; `HydraKit.TgWs` (AES-CTR на чистом Swift) |
| 4 | iOS: вкладки «Маршрутизации» | «Обход DPI» / «Сайты и IP» / «Выходы» |
| 5 | iOS: настройки подбора | пауза, запросы, параллельность, таймаут, SNI, списки и свои, свои стратегии, все результаты, копирование |
| 6 | iOS: кнопка Telegram | `tg://proxy` для TG WS, `tg://socks` для ByeDPI |
| 7 | Убрать упоминания авторов идей | интерфейс (5 языков), код, документы, THIRD_PARTY_NOTICES |
| 8 | CI | один повтор e2e при сбое сети раннера |

## Не вошло

- Новые скриншоты README (телефон и ПК); проверка на телефоне Android и на устройстве iOS; fake-TLS (`ee`-секрет) MTProto-прокси; запасной путь через Cloudflare.

## Критерии готовности и что проверено

- Юнит-тесты: `TgWsProxyTest` (ПК), `TgWsTests` (HydraKit, Linux, 83 теста в пакете); живые тесты `TgWsLiveTest` против серверов Telegram (obfuscated, открытый abridged, MTProto-прокси).
- Компиляция: `:app:compileNativeDebugKotlin`, `:desktop:*`, iOS CI (SwiftUI и расширение).
- Не проверено: сессия Telegram на телефоне (Android) и на iOS.
