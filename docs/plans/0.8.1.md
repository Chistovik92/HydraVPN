# План 0.8.1 — Панели 1: 3x-ui, s-ui, x-ui

Источник: [`ROADMAP.md`](../ROADMAP.md), раздел 0.8.1. Опирается на SSH-слой и установщик из [0.8.0](0.8.0.md).

> **Состояние на 14.10.2026: альфа-сборка `0.8.1-a`, не выпущена, ветка `claude/0-8-1-alpha` не влита в `master`.**
> По схеме версий владельца (см. [`ROADMAP.md`](../ROADMAP.md#схема-версий-решение-владельца-12102026)) 0.8.1 выходит пре-релизом (`0.8.1-a`) без слияния в `master`, пока не проверен 0.8.0-rc2 и не выпущен 0.8.0.
> Разработка остановлена по решению владельца после проверок; ниже — что сделано, чем проверено и что осталось.

## Решения владельца

- **11.10.2026 — для 3x-ui вход в API по токену** (`Authorization: Bearer`), не по cookie-сессии. Токен выдаёт сам установщик (`/etc/x-ui/install-result.env`, `XUI_API_TOKEN`), работает для всех `/panel/api/*`, CSRF не нужен.
- **12.10.2026 — схема версий:** `X.Y.Z`, пре-релизы `-a` (альфа), `-b` (бета), `-rcN`; ветка альфы в `master` не вливается до проверки.
- **13.10.2026 — экраны для людей без технической подготовки:** все экраны «Мои серверы» — пошаговый мастер простым языком, понятные ошибки с советом, инструкция [`docs/SERVERS.md`](../SERVERS.md).

## Сделано (в ветке `claude/0-8-1-alpha`)

### Панель 3x-ui — ядро (`shared/.../servers/`)

| Файл | Что |
|---|---|
| `XuiPanel.kt` | Каталог (`PanelKind.XUI3`), запись панели `PanelInstance` (адрес, логин, пароль, токен, версия, id инбаунда и клиента), клиент API `XuiApi` (настройки, статус, инбаунды, ключи Reality, создание/удаление инбаунда и клиента, ссылки клиента, список клиентов) с двумя транспортами — напрямую по HTTP (`DirectXuiTransport`) и через `curl` на самом сервере по SSH (`SshXuiTransport`); план установки `XuiPanel.installSteps`; инбаунд VLESS + Reality по умолчанию |
| `MyServerService.kt` | `deployXui`: проверка → установка закреплённым тегом (последний выпуск узнаётся через GitHub API и показывается до запуска) → чтение токена из `install-result.env` → ожидание готовности панели → инбаунд Reality (ключи создаёт сама панель) → клиент `hydra-1` → готовая ссылка; `planPreviewXui`, `uninstallXui` |
| `MyServersManager.kt` | Вид «панель» в мастере (`ServerKind.PANEL_3XUI`), клиенты панели **по токену без входа по SSH**: `loadPanelClients`, `addPanelClient`, `showPanelLinks`, `removePanelClient`; удаление панели; `previewState` для скриншотов |
| `MyServer.kt` | Поле `panel` в записи «Моего сервера» (JSON) |
| `Installer.kt` | Вырезание токена из журнала, `addSecret` (секрет, появившийся по ходу установки) |

Принятые решения по безопасности: параметры установки (логин, пароль, порт) передаются файлом `0600`, а не в командах; журнал установщика (в нём печатаются логин, пароль и токен) при успехе не читается, при сбое показывается с вырезанием и удаляется; перед установкой проверяется, что 3x-ui на сервере ещё нет; тег проверяется регуляркой (нельзя подсунуть команду); порт панели в файрволе открывается только по явному согласию.

### Экраны для людей без технической подготовки (ПК и Android)

- Мастер из **6 шагов** («Что установить» → «Данные сервера» → «Это ваш сервер?» → «Проверка» → «Установка» → «Готово»): у каждого поля подсказка простыми словами; «Дополнительно» свёрнуто; отпечаток сервера объяснён как «номер паспорта»; проверка сервера — зелёные/красные пункты с советом; «что мы сделаем» — по одной простой фразе, команды — под спойлером «для опытных»; экран «Готово» говорит, что делать дальше (для панели — адрес, логин, пароль, «Открыть панель»).
- `FriendlyText.kt` — **перевод ошибок на человеческий** (неверный пароль, нет ответа, отказ, неизвестный адрес, нет интернета, повреждённый файл, смена отпечатка, порт занят, панель уже стоит и др.): «что случилось» + «что делать»; подробности и «Скопировать подробности» под спойлером. Русский и английский (Android выбирает по языку приложения, ПК — русский).
- Карточки серверов без жаргона: «Устройства, которым разрешено подключаться» (не «клиенты»), «Показать доступ», «Добавить устройство»; панель — «Открыть панель» (пароль копируется в буфер), «Пользователи», «Добавить пользователя», «Ссылка»; «Удалить с сервера» и «Убрать из списка» объяснены.
- Приветственная карточка «Свой VPN за несколько минут» («Что понадобится»), кнопка «Что это такое?», ссылка «Как арендовать сервер».
- Инструкция [`docs/SERVERS.md`](../SERVERS.md): аренда сервера, шаги, как подключить ещё устройство, как удалить, частые вопросы.
- Android: строки en/ru (`strings_myservers.xml`); ПК: `MyServersScreen.kt`.

### Исправления, найденные по пути (в `master` уже вошли через 0.8.0-rc2)

R8 вырезал JSch в release (rc2), порядок серверов подписки, процессы ядер на Windows — см. CHANGELOG 0.8.0-rc2.

## Чем проверено

- **Юнит-тесты (ПК):** `XuiPanelTest` (клиент API на поддельном HTTP-сервере: заголовок Bearer, ответы, ошибки; план установки; разбор файла результата; вырезание токена; весь `deployXui` на поддельном SSH), `FriendlyTextTest` (ошибки, проверки, план, английский), отрисовка экранов.
- **Живой прогон на настоящем Linux (WSL, Ubuntu 26.04):** установка 3x-ui **v3.10.0** из GitHub (последний выпуск на момент проверки; v3.9.0 проверен раньше), токен принят снаружи по сети, инбаунд VLESS+Reality и клиент созданы, готовая ссылка импортирована, второй пользователь добавлен без входа по SSH, секретов в журнале нет, удаление панели чистое (`XuiLiveTest`, `HYDRA_XUI_LIVE=1`).
- **Эмулятор Android 15 (debug-сборка):** мастер от выбора «Панель 3x-ui» до экрана «Готово» на тестовом сервере (WSL): панель установлена, логин/пароль показаны, подключение «Hydra-hydra-1» появилось в «Серверах».
- **Скриншоты экранов ПК** (все шаги, ошибка, карточки) — просмотрены, поправлены дубли текста и цвет галочек.

## Не проверено

- Настоящий VPS (Debian/Ubuntu, x64 и arm64) — только WSL; пакеты arm64/armv7 серверного AmneziaWG не запускались.
- **Release-сборка Android** с новыми экранами (R8): проверялась debug; правила R8 для JSch проверены на rc2, для панели нужного не требуется (`org.json` + HTTP), но прогон на release не делался.
- Ссылка клиента строится панелью по заголовку `Host` запроса — на тестовом стенде с адресом `10.0.2.2` в ссылке получается он же; на настоящем VPS — внешний адрес сервера (проверить).
- Windows-портативная версия: новые экраны в живом окне не смотрелись (только отрисовка в тестах).
- Кнопка «Открыть панель» на Android открывает браузер (не встроенный WebView).

## Методы API 3x-ui (v3.10, по `docs/public/openapi.json` апстрима)

| Что | Метод |
|---|---|
| Проверка токена, настройки | `POST /panel/api/setting/all` |
| Состояние сервера | `GET /panel/api/server/status` |
| Ключи Reality | `GET /panel/api/server/getNewX25519Cert` |
| Инбаунды | `GET /panel/api/inbounds/list/slim`, `POST /panel/api/inbounds/add`, `POST /panel/api/inbounds/del/{id}` |
| Клиент | `POST /panel/api/clients/add` (`{client:{email,subId,totalGB,expiryTime,limitIp,flow,…}, inboundIds:[…]}`), `POST /panel/api/clients/del/{email}`, `GET /panel/api/clients/list` |
| Ссылки клиента | `GET /panel/api/clients/links/{email}` — готовые `vless://…`, годятся для импорта без сервера подписки |

## Как продолжить

1. Ветка: `claude/0-8-1-alpha` (отправлена на GitHub, **не вливать в `master`**). Сначала подтянуть `master`, если вышел 0.8.0.
2. Проверка: `gradle :desktop:test :app:testStubDebugUnitTest`; живые тесты на Linux (WSL с sshd на порту 2222): `HYDRA_SSH_TEST=host:port:root:пароль HYDRA_XUI_LIVE=1 gradle :desktop:test --tests *XuiLiveTest*` (установка и удаление 3x-ui по-настоящему), `HYDRA_AWG_BUNDLE=dist/awg-server/amd64` — для AmneziaWG (`AwgServerLiveTest`, `MyServersTest`).
3. Скриншоты экранов ПК: `HYDRA_SCREENSHOTS_DIR=каталог gradle :desktop:test --tests *MyServersShotsTest*`.
4. Эмулятор Android: AVD `hydra35`; на нём сеть к WSL — через `10.0.2.2` и ретранслятор на хосте; клавиатуру отключить (`settings put secure show_ime_with_hard_keyboard 0`).
