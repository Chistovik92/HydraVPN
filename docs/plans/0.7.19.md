# План 0.7.19 - PPTP

Запрос владельца 10.10.2026: PPTP во всех версиях, для мобильных платформ - новый код (выпущено в тот же день).

## Задачи и результат

| № | Задача | Результат |
|---|---|---|
| 1 | Движок PPTP | `:shared` `vpn/pptp`: сообщения управляющего канала (TCP 1723), улучшенный GRE с номерами и подтверждениями, MPPE 128 бит (stateless и stateful, RFC 3078/3079), `PptpClient` |
| 2 | Android | `PptpCore` поверх `PppSession` (CCP/MPPE добавлены); GRE через root-помощника `GreRelay` (`su` + `app_process`, `SOCK_RAW/47`, SO_MARK сети); без root - понятная причина |
| 3 | Windows | встроенный RAS: `Add-VpnConnection` + `rasdial` (`WindowsPptp`), слежение за обрывом, снятие при отключении/выходе/запуске |
| 4 | Ссылка и интерфейс | `pptp://user:pass@host:порт#имя`, параметр `mppe=off`; тексты в настройках (5 языков), `Protocol.PPTP` -> `Engine.USERSPACE` |
| 5 | Чистка | `skip` в разборе `.dat`, атомарная запись `meta.json` geo-баз |

## Решение по платформам

- iOS: расширение VPN не умеет GRE (нет raw-сокетов) - порт движка не делался, PPTP остаётся недоступным.
- Linux, macOS: встроенного клиента нет (macOS убрала PPTP в 10.12); свой GRE на ПК потребовал бы root - не делался.
- Сторонних ядер с PPTP (sing-box, Xray) нет, поэтому код собственный.

## Не вошло

- Удаление мёртвого кода заготовки (`desktop/src/{commonMain,desktopMain,desktopTest}`, `shared/.../vpn/ppp`, `shared/.../desktop`, `shared/.../vpn/core`).

## Критерии готовности и что проверено

- `PptpTest` (ПК): вектор RC4 (RFC 6229), MPPE stateful/stateless (в т. ч. смена ключа каждые 256 пакетов и потеря пакетов), размеры и разбор сообщений, GRE, сквозной тест клиента с поддельным сервером.
- Компиляция: `:app:compileNativeDebugKotlin`, `:app:testStubDebugUnitTest`, `:desktop:test`, `:desktop:compileLiteKotlin`.
- Не проверено: реальный сервер PPTP (ключи и режимы MPPE сверены по RFC и поведению pppd), устройство с root, Windows RAS на живом сервере.
