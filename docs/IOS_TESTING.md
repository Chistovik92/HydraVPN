# Тестирование iOS: TestFlight

Как проверять Hydra на iPhone и iPad. Сейчас iOS-клиент собирается только в macOS-CI **без подписи** (неподписанный `.ipa`
в каждом релизе) — на устройство его так не поставить. Ниже: (1) эталонный клиент OpenFlux из TestFlight — для проверки
узлов и ссылок OpenFlux уже сейчас; (2) как завести TestFlight для самой Hydra; (3) что делать тестировщику; (4) что
проверять. Связанный план — [plans/0.7.11.md](plans/0.7.11.md), блок E.

## 1. Бета OpenFlux в TestFlight (эталон для сверки)

Публичная бета iOS-приложения «Openflux» от автора ядра OpenFlux: <https://testflight.apple.com/join/BwnAcdus>.
Это **не Hydra** — сторонний клиент того же ядра. Нужен, чтобы отделить проблемы узла/транспорта от проблем Hydra:
если узел не работает и в «Openflux», дело не в Hydra.

Установка (iPhone/iPad с iOS 16 или новее):

1. Установите **TestFlight** из App Store.
2. Откройте ссылку выше **на самом устройстве** (в Safari) → «Просмотреть в TestFlight».
3. В TestFlight: «Принять» → «Установить». Рядом с названием приложения появится оранжевая точка — признак беты.
4. Сборка доступна 90 дней с загрузки; включите в TestFlight «Автоматические обновления», чтобы получать новые.
5. При входе по публичной ссылке разработчик не видит ваше имя и почту — только число сеансов, сбоев и версию.

Сверка с Hydra:

- одна и та же ссылка `openflux://v1/…` (из узла владельца или из OpenFluxAndroid/Desktop) должна подключаться и в
  «Openflux», и в Hydra (Android, ПК, iOS) — после блока B плана 0.7.11;
- если «Openflux» подключается, а Hydra нет — это ошибка Hydra: приложите журнал Hydra (Настройки → Логи → Сохранить) и
  ссылку **без ключа** (ключ в ссылке — секрет, как пароль).

Ограничение апстримной беты: по её документации (`ios-app/DISTRIBUTION.ru.md` ядра, сборки сентября 2026) она поднимает
только локальный SOCKS5 (`127.0.0.1:1080`), без системного VPN; если в текущей сборке появился режим VPN — сверять и его.
Для проверки «весь трафик через туннель» эталоном пока служит OpenFluxAndroid.

## 2. TestFlight для Hydra (владельцу проекта)

### 2.1. Что нужно один раз

1. **Apple Developer Program** (99 $ в год). Для внутреннего тестирования хватает аккаунта частного лица; для публикации
   VPN-приложения в App Store Apple требует аккаунт **организации** (App Review Guideline 5.4) — учесть заранее.
2. **Идентификаторы** (developer.apple.com → Certificates, Identifiers & Profiles → Identifiers), как в `ios/project.yml`:

   | Таргет | Bundle ID | Возможности |
   |---|---|---|
   | Приложение Hydra | `ru.gidravpn.hydra` | App Groups, Network Extensions |
   | Расширение sing-box (`HydraTunnel`) | `ru.gidravpn.hydra.tunnel` | App Groups, Network Extensions (Packet Tunnel) |
   | Расширение AmneziaWG (`HydraAWG`) | `ru.gidravpn.hydra.awg` | App Groups, Network Extensions (Packet Tunnel) |
   | Виджеты (`HydraWidgets`) | `ru.gidravpn.hydra.widgets` | App Groups |

   App Group: `group.ru.gidravpn.hydra` (общая для всех четырёх).
3. **App Store Connect** → «Мои приложения» → «+» → новое приложение: платформа iOS, Bundle ID `ru.gidravpn.hydra`,
   SKU — любой (например `hydra-ios`).
4. **API-ключ** (App Store Connect → Пользователи и доступ → Интеграции → App Store Connect API → «+», роль
   «App Manager»): скачать `AuthKey_<KEY_ID>.p8` (скачивается **один раз**), записать Key ID и Issuer ID. Ключ — секрет:
   не коммитить, хранить вне репозитория; при утечке — отозвать там же.
5. **Секреты репозитория** (GitHub → Settings → Secrets and variables → Actions): `ASC_KEY_ID`, `ASC_ISSUER_ID`,
   `ASC_KEY_P8` (содержимое `.p8`), `APPLE_TEAM_ID` (10 символов, developer.apple.com → Membership). С ними задача CI
   «Подпись и выгрузка в TestFlight» (план 0.7.11, блок E) начнёт работать; без них — пропускается.

### 2.2. Каждая сборка

- CI подписывает архив автоматически (через API-ключ), номер сборки — номер запуска CI (Apple не принимает повторный
  номер), и выгружает `.ipa`: `xcrun altool --upload-app -f Hydra.ipa -t ios --apiKey "$ASC_KEY_ID" --apiIssuer "$ASC_ISSUER_ID"`.
- Через 5–30 минут сборка появляется в App Store Connect → TestFlight («Обработка» → «Готово к тестированию»).
- Флаг `ITSAppUsesNonExemptEncryption = false` в Info.plist избавляет от вопроса об экспортном шифровании (используется
  только стандартное шифрование протоколов) — проверить формулировку для VPN перед первой внешней выгрузкой.

### 2.3. Тестировщики

- **Внутреннее тестирование** (до 100 человек из команды App Store Connect): без ревью Apple, сборка доступна сразу.
- **Внешнее тестирование** (до 10 000, по почте или **публичной ссылке** вида `https://testflight.apple.com/join/XXXXXXXX`):
  первая сборка каждой версии проходит Beta App Review (обычно до суток). Для VPN-приложения в «Что тестировать» и в
  описании беты указать: назначение, что нужен свой сервер/подписка, тестовый профиль для проверяющего Apple.
- Публичную ссылку Hydra, когда появится, добавить в README рядом со ссылками на загрузку.

### 2.4. Без платного аккаунта

Бесплатный Apple ID (Xcode «Personal Team», AltStore, Sideloadly) **не даёт права Network Extension** — приложение
установится, но VPN не поднимется. Поэтому до Apple Developer Program на iPhone проверяется только эталонная бета
OpenFlux (раздел 1), а Hydra для iOS — сборкой и тестами в CI.

## 3. Тестировщику Hydra

1. Установите TestFlight, откройте публичную ссылку Hydra на устройстве, «Принять» → «Установить».
2. Первый запуск: разрешите «Добавить конфигурацию VPN» (iOS спросит код-пароль), уведомления — по желанию.
3. Добавьте сервер: подписка или ссылка (vless/trojan/ss/hy2/tuic/wireguard/awg/olcrtc/openflux), QR — камерой.
4. Отзыв: скриншот → «Поделиться отзывом о бета-версии» (или TestFlight → Hydra → «Отправить отзыв о бета-версии»),
   до 4000 символов; при сбое iOS сама предложит отправить отчёт — нажмите «Поделиться».
5. К отзыву приложите журнал: Hydra → Настройки → Логи → «Сохранить» (ключи и пароли в журнал не пишутся).

## 4. Что проверять на iOS (чек-лист сборки)

| Сценарий | Ожидание |
|---|---|
| Подключение VLESS/Reality, Trojan, Shadowsocks, Hysteria2, TUIC, WireGuard | «Подключено», сайты открываются, IP на ipleak.net — сервера |
| AmneziaWG (отдельное расширение) | то же |
| olcRTC (своя комната Телемоста/Jitsi), OpenFlux (`direct` и документ) | подключается внутри расширения; при ошибке — понятная причина в журнале |
| Wi-Fi ↔ LTE/5G во время работы | туннель не зависает (исправление 0.7.9) |
| Долгая загрузка (1–2 ГБ) | скорость не падает до нуля, нет обрыва |
| Kill Switch, автоподключение (On-Demand) | трафик не идёт мимо туннеля; после перезагрузки подключается сам |
| Темы и иконка приложения (Настройки → Тема) | смена иконки — системное подтверждение iOS, затем новая иконка |
| Память расширения (olcRTC с видеоканалом) | расширение не завершается системой; если завершается — отметить в отзыве |
| Ссылка `openflux://v1/…` из «Openflux» TestFlight | импортируется и подключается (после 0.7.11) |
